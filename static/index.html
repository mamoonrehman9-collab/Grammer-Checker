What GrammarLens checks

Every check is a transparent rule or dictionary lookup. Nothing is guessed by a hidden model.

Spelling

Dictionary lookup with pyspellchecker, a list of common misspellings, and skips for names, acronyms and contractions.

Articles and agreement

a / an by sound (an hour, a university), he go, they was, everyone are, those is.

Confused words

their / there / they’re, its / it’s, your / you’re, then / than, affect / effect, to / too.

Verb forms

I seen, did went, can goes, double comparatives such as more faster, much / many.

Punctuation and spacing

Extra spaces, space before or after punctuation, missing question mark, comma after However, unmatched quotes.

Style

Filler words, wordy phrases, clichés, passive voice and very long sentences. Readability uses the Flesch formula.

About the model

GrammarLens is a rule-based NLP system. Python and FastAPI run the engine, and this page talks to it through one endpoint, POST /api/check.

Evaluation

55 hand-written test sentences: precision 1.00, recall 1.00, F1 1.00. The tests were written for the rules themselves, so the score is optimistic.

Limits

Rules match patterns and do not understand context. A real word used wrongly, such as form for from, is not caught.

Stack

Python, FastAPI, pyspellchecker, regular expressions, HTML, CSS and JavaScript.
